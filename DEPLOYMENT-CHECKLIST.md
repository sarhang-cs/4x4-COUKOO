# Deployment checklist

1. Upload this source project to the `main` branch.
2. Wait for Vercel to finish `npm run build`.
3. Open the site once online so the service worker receives the new cache version.
4. Reopen the site and test Low, Medium and High; then test Auto FPS and one manual FPS mode offered by the browser.
5. Test Rain, Storm, Snow and one season override from Settings.
