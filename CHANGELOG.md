# Changelog

## v1.15.0 — Responsive UI and runtime cleanup

- Removed Coukoo Garage, daily rewards, mission currency, and the top-of-screen coin HUD.
- Removed obsolete garage runtime modules and their saved progress values.
- Added safe-area and visual-viewport layout handling for mobile Safari, Android browsers, tablets, and desktop.
- Improved menu and settings scrolling to avoid clipping or non-scrollable panels on iPhone-class devices.
- Strengthened device capability profiling and startup frame-cadence calibration without guessing hidden hardware facts.
- Tuned Medium/High rendering budgets for observed strong mobile browser profiles and softened adaptive-resolution changes.
- Restored README screenshots and updated release documentation.
- Updated service-worker cache to v1.15.0.
